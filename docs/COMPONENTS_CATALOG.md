## 6. Bootstrap & Foundations (8 items)

- `init`: Base setup pulling Tailwind theme tokens, `cn()`, and dark mode helpers.
- `tailwind`: Canonical Tailwind CSS v4 OKLCH tokens and base styles.
- `utils`: Core `cn()` utility (`clsx` + `tailwind-merge`).
- `use-theme`: Dark/light mode theme composable / hook with system preference support.
- `use-kanban`: Headless drag-and-drop kanban state management.
- `use-board`: Multi-column board state engine.
- `use-month-grid`: Calendar day / week / month date grid calculations.
- `motion-list`: Micro-animation stagger helper for item transitions.
